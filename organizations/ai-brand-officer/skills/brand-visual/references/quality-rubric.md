# 品牌视觉质量量表

## 双审核

每个候选先由 `ruleReview` 执行规则审核，再由没有继承执行者自评和辩护的 `professionalReview` 执行独立专业审图。视觉专业审核只读任务、证据、候选和本量表；两个审核者身份与记录必须不同。任一审核失败均不得交付。

普通海报还必须执行 `poster-quality-rubric.md` 的十项硬否决、六维 100 分和七项横向对比。海报命中硬否决即淘汰；未达到 80 分不得提交帝王候选。

## 规则审核

- 企业、项目、任务、Skill、模块和候选身份一致；
- 定位及其他上游均固定到 `artifactId@version` 与 `sha256`；
- 长期视觉模块存在来自品牌官、`brand-positioning-*` 语义正确的精确定位上游；临时海报/AI探索豁免不扩大到长期资产；
- 三个方向分别绑定唯一资产哈希，且三对方向差异证据完整、每对至少两个枚举视觉维度；重复图、漏 pair 或只改说明直接失败；
- 审美档案企业、项目、品牌与当前可信任务一致；跨项目档案必须有精确存在于可信上游授权中的固定导入快照；
- 公共能力正式调用同时通过根成熟度、组织许可和当前项目总控任务授权三重校验；
- 素材、字体、图片、人物、产品和生图通道授权可追溯；
- 产品身份指纹、原图哈希和支持视角完整；
- 所有精确文字可核对，AI 图不承担复杂精确文字；
- 概念、施工、法规、印刷和正式发布边界没有混淆；
- 未调用模块明确标为“本次未调用”；
- 候选只保存在当前项目的组织工作区，没有写入共享区或正式输出。

## 视觉专业审核

| 维度 | 通过标准 | 失败信号 |
| --- | --- | --- |
| 定位承接 | 视觉变量能解释主要心智、目标用户、场景和差异化 | 只有“高级、科技、黑金”等抽象词，或画面与定位冲突 |
| 区别度 | 与竞品、模板和常见 AI 套路存在可辨别差异 | 换品牌名即可给竞品使用，或高度复制参考 |
| 识别与延展 | Logo/字标、色彩、字体、图形、图像和版式形成系统，可在关键尺寸与场景延展 | 单张好看但品牌资产不识别，缩小、黑白或跨媒介即失效 |
| 产品原貌 | 产品结构、比例、颜色、材质、Logo、配件和可见视角与绑定原图一致 | 产品漂移、虚构视角、局部或功能结构 |
| 精确文字 | 品牌名、型号、价格、日期、参数、法规字段与二维码均由确定性排版核对 | 错字、乱码、漏字、未确认改写或 AI 伪文字 |
| 授权 | 字体、图片、人物、IP、产品素材和生图通道都有适用范围凭证 | 授权不明、越用途、素材授权被当成工具授权 |
| 系列一致 | 相邻页面分工、节奏、信息密度、光线、图形与字体属于同一体系且不重复 | 单图通过但整套割裂、重复、过空或节奏失衡 |
| 生产边界 | 概念、矢量重建、施工、结构、法规、刀模、印刷和发布状态准确标注 | 概念图冒充施工或建成；包装占位冒充生产稿 |
| 参考视觉 DNA 对照 | 候选转译构图、光线、色彩、字体、材质和留白原则，不复制表面 | 参考 DNA 被抽象风格词覆盖，或只剩廉价模板特征 |
| 独立专业审图 | 审核者依据可见结果、证据和固定量表作出结论 | 直接接受执行者“我认为合格”的自我说明 |

## 模块专项门禁

### 品牌视觉体系

检查黑白、反白、小尺寸、远视、数字/印刷、母子品牌关系和错误示例。AI 生成 Logo 只能做概念，正式候选必须确定性重建；公开相似性预查不等于商标法律结论。

### 门店形象

检查门头远视、导视路径、展示职责、材质真实性、昼夜灯光与现场边界。概念效果图必须醒目标记“非施工图”，没有实测与专业复核不得给施工、消防、电气、结构或造价结论。

### 产品包装

检查结构适配、信息层级、标签、法规字段来源、材质工艺、刀模和印刷边界。无企业或专业依据不得补造字段；视觉审核不替代法规、打样和印刷复核。

### AI视觉生成

检查人物、产品、授权、通道、当前版本绑定、生成痕迹与确定性排版。任何安全降级若改变已确认方向，必须重新确认。

## 结论等级

- `eliminated`：命中硬否决或存在无法补偿的真实性/授权/边界错误；
- `rework`：方向可保留但存在明确失败项，只能定向修复；
- `candidate_ready`：双审核通过，且海报类达到 80–89.999 分并通过全部必要比较；
- `preferred`：双审核通过，且海报类达到 90–100 分，或非海报候选在同轮证据和专业判断上明显更优。

偏好不能覆盖产品原貌、事实、授权、安全、精确文字、品牌定位和生产边界。
